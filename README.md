News & Climate AI Assistant

An AI-powered web application that delivers real-time news updates and weather information while maintaining conversational memory from previous chats. The application combines intelligent search, weather forecasting, and chat history awareness to provide personalized responses.

Live Demo: News & Climate AI Assistant(https://news-and-climate-ai.vercel.app/)

Features
* Real-time News Search using Tavily AI
* Live Weather & Climate Information using OpenWeather API
* Conversational AI Assistant
* Previous Chat Memory Retrieval
* Context-Aware Responses
* Fast and Responsive UI
* Deployed on Vercel

Tech Stack
* Frontend
* React.js
* Tailwind CSS
* JavaScript
* Backend
* Python
* FastAPI
* APIs & Services
* Tavily Search API
* OpenWeather API
* OpenAI / LLM Integration

Deployment 
* Vercel
* Render

📌 How It Works
-> User asks a question.
-> The AI determines whether the query requires:
-> News information
-> Weather information
-> Previous chat context
-> Tavily API fetches the latest news.
-> OpenWeather API retrieves real-time weather data.
-> Chat history is searched to retrieve relevant previous conversations.
